# Restore Xi'an cooperation requirements for enterprise evaluation

The [original-source pilot](../enterprise-eligibility-pilot-v1)
found an unindexed field in the original Xi'an forms. Reopen the
six fixed attachment archives. Join each original cooperation
field to the same numbered form as its technical title and body.
Use these fields to construct a restored text view for the overlap
screen. Keep technical text and cooperation requirements separate
in the private evaluation input. The restoration preserves the
published text in both fields except for known contact patterns.
A separate source view preserves the original screening decisions.

Reproduce all 530 original groups before running the original
issuer, exact and four-gram overlap rules again against every
restored candidate row and the same 4,301 historical records.
The two screens use separate text representations. A group
is eligible for the provisional holdout view only when both
screens produce the same representative and exact membership
hash. Quarantine any original nonpilot group failing that test.
Never admit a new group solely because the restored screen
creates it. Independently exclude all 65 fixed pilot groups,
even if both screens preserve them. This approach can exclude
more than a combined graph would require. It keeps the later
test insulated from known source or group changes.

Only the Xi'an field has been restored in this revision. The
source context of other publication formats remains subject to
the original-source review. Cooperation fields may contain
preferences, eligibility, or administrative material. Hard
requirements still need independent judgment. Neither projection
provides search results, human relevance labels, or evidence of
all forms of semantic independence.

## Results

The restored text includes 300 originally published Xi'an fields.
Among the 530 frozen representatives, 241 carry a restored field.
That comprises 30 of the 65 pilot groups and 211 of the 465
provisional holdout groups. Both lexical screens select all 530
of the same representatives with identical membership hashes.
Both still link 19 source rows to historical exposure. No
additional group is admitted or quarantined under the shared
group rule. Two independent parser hash seeds reproduce
the private output byte for byte.

The restored input is a structured pair of technical body
and cooperation field for the affected format. Separate metadata,
including Jiangyan's intended collaboration type and Zibo's
cooperation, investment, and existing-work fields, still needs a
source-specific audit. These source schema observations leave the
existing benchmark freeze intact.

## Reproduce

Use the [compendium replay](../enterprise-public-compendium-v4#reproduce)
and the original pilot packet. Request a fresh private frame,
aggregate and output folder. Append

```sh
--cooperation-projection FROZEN_PILOT_DIRECTORY NEW_PRIVATE_PROJECTION_DIRECTORY
```

The output directory contains separate, private pilot,
provisional-holdout, and quarantined JSONL files. The receipt
summarizes both lexical screens. Text, locators, and group-level
records remain outside Git.
