\label{app:protocols}
\subsection{Ownership and source views}
Every view binds a query ID, expert ID, source ID, text hash, and character interval. The raw corpus retains full field text, while evaluation sees only frozen ranges. Expanding a source silently changes the labeled task. Ownership checks establish consistency with supplied associations, not real-world authorship or individual contribution. Source frames have globally unique keys formed from source ID and local frame ID. Repeated IDs, stale hashes, foreign quotations, and unadmitted cached frames are rejected. A null field means unreported, never impossible.

The 100-source stratified, query-blind frame pilot contains 40 papers and 15 each of projects, patents, biographies, and research-field lists, all from development sources. It admits 26 frames from 23 papers. Nineteen frames have documented inputs, 24 outputs, and 16 conditions; 45 quotations are exactly bound. All 100 sources remain raw-retrieval eligible. No frame survived screening in the 60 profile fields; sampled fields were often titles, broad areas, or publication counts. This does not imply lack of expert methods, and compilation itself can miss evidence. The pilot is not a complete searchable frame index or an amortization result.

\subsection{Publication and contribution metadata}
Original paper records number 54,409. Of these, 53,007 have parseable dates: 30,827 year-, 4,450 month-, and 17,730 day-resolution dates. There are 48,657 known citation totals, 53,750 author-list strings, and 8,034 DOIs. Explicit personal-contribution roles are absent. At a 2025-12-31 cutoff, 2,616 publications fall after the cutoff, 50,391 before/on it, and 1,402 have unknown dates. Year-only intervals overlapping a cutoff are not fabricated into exact dates. Current citation totals have no observation timestamps, so historical citation scoring is unsupported.

The sidecar preserves dates, raw author-list text, paper-level counts, and unknown personal credit without rewriting frozen source vectors. Author order, supervision, or high citations alone do not identify honorary authorship. Future verification must distinguish identity association, explicit method contribution, project responsibilities, and team-level evidence. Field- and age-normalized impact cannot be claimed when the required metadata are unavailable.

\subsection{Role-aware fixed-view gain}
A complementary reporting protocol treats method support, the person's contribution to the method, and temporal eligibility as separately judged requirements for a fixed query--expert--source view. A view is supported only when all three are supported; an explicitly unsupported requirement makes the conjunction unsupported, while missing judgments remain unknown. Discounted lower and upper bounds use the same fixed output budget, with missing result positions receiving zero gain. Author order and citation totals do not supply personal-contribution labels. This is standard interval arithmetic conditional on annotations, not a new theorem or a measure of actual expert ability.

On 80 reused private development needs, the first five results produce 400 views. None has independently supplied fixed-view judgments for the three dimensions or a requested cutoff, so every joint label is unknown and the mean interval is $[0,1]$. These vacuous bounds make the annotation gap explicit; they do not rank systems or establish an accuracy result. Fixed-view identities bind query, expert, displayed source and cutoff. Labels from a changed source or time scope cannot be silently reused.

\subsection{GPU full-source scoring}
An experimental CUDA component stores the frozen FP32 source matrix on an allocated GPU, computes every source score for one query, transfers scores to the CPU and aggregates experts and sources. With TF32 disabled, Slurm job 39636 on an RTX~5090 matches the CPU exact reference's expert and first-source order on 2,000 previously explored bilingual views. The maximum absolute score difference among shared top-ten experts is $3.58\times10^{-7}$; this is observed agreement, not bitwise or universal equivalence. Mean cached scoring is 0.997 ms on GPU versus 8.886 ms on one CPU thread, including device transfers and CPU aggregation. The GPU matrix adds 396,361,728 allocated bytes and peak PyTorch allocation is 430,307,328 bytes, excluding reserved memory and context. One alternating-order observation per view excludes query encoding, initialization, index/model construction, reasoning and concurrent service load. The comparison does not establish independent relevance, whole-agent speed or quality. The scorer also supports an explicit eligible set. Across 2,000 views with a lexical top-50 shortlist, GPU and CPU selected expert/evidence orders match; selected scoring averages 0.540 versus 0.934 ms. The candidate-LM-plus-GPU path averages 3.376 ms versus 0.983 ms for GPU full scoring and retains 33.99\% of the full-vector top ten. This is ranker agreement, not relevance recall; encoding, initialization and concurrent load are excluded.

\subsection{Shared exact-reference snapshot}
An exact reference can reuse an owned index's read-only vector array while copying ownership containers. On 400 previously examined bilingual pairs, all non-timing fields of 800 exact results match the independently allocated reference. This avoids a 396,283,904-byte duplicate vector array; graph storage, metadata, the original mapped file and process overhead are excluded. One fixed-order construction takes 0.025 versus 0.091 seconds, while mean query times are 8.787 versus 8.791 ms. This is not evidence of query-speed or relevance improvement. The shared snapshot must remain unchanged; read-only flags are not a security boundary and concurrent mutation is unsupported.

\subsection{Adaptive nearest-neighbor effort}
On 400 previously examined bilingual construction pairs, a score-gap heuristic first searches with HNSW effort 64 and increases it to 512 when the tenth and eleventh expert scores differ by at most 0.002. It escalates 404 of 800 language views. Mean cached search is 1.15 ms versus 1.67 ms at fixed effort 512, but exact top-ten retention falls from 99.7875\% to 97.9875\%; ordered expert and top-source lists match the exact reference on 674 versus 783 views. A follow-up calibrates fixed gaps under a 99.5\% mean top-ten retention target on the first 400 pairs; direct effort 512 is the fastest eligible policy. On the remaining 600 previously explored pairs it retains 99.8167\% of exact entries, matching 1,179/1,200 ordered lists. Repeated timing of that same policy is not an algorithmic speedup. The rule cannot bound unseen candidates, and this reused cohort has no independent expert-fit labels. Index construction, query encoding and model reasoning are excluded from query timings; the measured fidelity loss does not justify adopting the gate by default.

\subsection{Numeric provenance diagnostic}
We compare values detected in each of 5,000 generated bilingual query pairs against the cited source segments and complete parent need. Thirty pairs contain at least one detected value absent from the full parent; one had passed the earlier same-model screen and 29 were unjudged. The parser may miss spelled-out quantities or mistake identifiers for quantities; it checks values, not units, arithmetic, comparator, object scope or semantic support. Thus these are review flags rather than hallucination labels. A local blinded packet pairs all 30 flags with 30 numeric-bearing controls matched by intent and earlier status. All 180 human grounding and equivalence judgments remain missing; this targeted sample is not a population error estimate. An additional same-family model review labels at least one language changed or unsupported in 11/30 flagged and 13/30 matched control cases. It labels the single previously retained flagged pair supported in both languages. These model judgments are not independent human validation and do not resolve the flags. A versioned recheck finds one possible spaced-minus interpretation among the 30 flags; 29 remain absent under both parses. A dash can also mean a range or bullet, so the alternative is ambiguous and no existing status is changed. Two additional post-hoc cross-language format hints mark 12 of the remaining 29 as possible matches, leaving 17 still flagged. These literal hints do not establish semantic equivalence or confirmed errors.

\subsection{Public bilingual backtranslation pilot}
We translate the titles and abstracts of 20 previously explored CoF SIGIR queries into Chinese. Nineteen Chinese views are available; the missing translation remains unknown. The generated views are not independently verified. The same-model screen accepts ten of the 19 and leaves eight unjudged and one unresolved. Reviewer-level labels are transferred to each translation only conditionally: they measure topic matching if the translations preserve meaning, not enterprise expert fit or source entailment. On the 19 available pairs, original-English and Chinese soft P@5 are 0.421 and 0.442; hard P@5 are 0.168 and 0.189. The mean top-ten overlap is 0.747. Paired query bootstrap intervals for both P@5 differences include zero. These cases were already used during development and are not held out.

A follow-up uses a model to translate each available Chinese view back into English. It receives neither the original English query nor the reviewer labels. All 19 backtranslations are available; 17 pass the same-model screen, but only nine pass both screens. Fixed reciprocal-rank fusion with constant 60 combines complete judged-candidate lists from Chinese and backtranslated queries without label tuning. Chinese, backtranslation and fusion soft P@5 are 0.442, 0.411 and 0.442; hard P@5 are 0.189, 0.211 and 0.211. The fusion-minus-Chinese hard P@5 difference is 0.021, with an unadjusted paired query bootstrap interval of $[-0.032,0.095]$. The missing twentieth query is not treated as a failure: its full-cohort hard P@5 bounds are $[0.180,0.230]$ for Chinese and $[0.200,0.250]$ for fusion. These broad bounds condition on the transferred labels, not independently assessed relevance.

The mean backtranslation call takes 3.168 seconds for 19 successful requests, excluding audit calls. An allocated RTX~5090 encodes the 38 views in one 0.283-second batch after initialization; this is throughput, not single-query latency. Fresh and earlier Chinese encodings have mean cosine 0.999905 and mean top-ten overlap 0.979, illustrating that even the repeated embedding pipeline need not reproduce every rank. This exploratory result neither establishes a quality gain nor supports a faster end-to-end system. The model screen is correlated with generation, semantic fidelity needs blind human review, and public reviewer relevance does not establish expert capability.

\subsection{Synthesis and bilingual controls}

An order-controlled audit of 30 selected real cases shows that the original joint grounding question is sensitive to presentation: 71 of 120 choice-order comparisons disagree. A later single-view instruction, with different inputs and target, yields 3 and 4 disagreements among 60 views in two sequential rounds; five of 120 same-order answers change between rounds. These are unjudged cases and the designs differ, so neither accuracy nor a causal prompt improvement follows. Simple single-view synthetic controls pass all tested choice orders but do not establish real-data reliability. A separate blind review package contains 30 unjudged cases, six per intent type.

Construction-screen coverage differs across intent types. Of 1,000 pairs per type, 115 component-method, 74 conditional-transfer, 279 constraint-focused, 212 evidence-lookup and 96 overview pairs remain unjudged. Filtering to screened pairs therefore changes the type distribution. Five original needs have no retained pairs, while 550 have all five. These are screen-coverage counts, not human error rates. A separate local review packet samples ten cases from each type and screening-status stratum, hides screen status, and currently contains no completed human judgments. Uncertain and missing judgments remain unknown; population-weighted sample intervals must not be mistaken for confidence intervals.

We separately retrieve paper and profile candidates and fuse their top-50 lists with reciprocal rank fusion (RRF). Exact fusion increases mean bilingual overlap@10 from 0.4216 to 0.4961 across the same 1,000 construction pairs; interleaving reaches 0.4644. Both channel shortlists contain 83.34\% of RRF output slots versus 33.64\% for interleaving. Approximate RRF retains 99.545\% of exact fused top-ten entries in 13.52\,ms per view, excluding encoding, loading, and index construction. Relevance and end-to-end superiority require independent evaluation.
Raw enterprise data contain 4,301 nonempty needs. The new company-grouped cohort excludes 136 prior need IDs and 1,424 additional records sharing exact prior-company keys, leaving 2,741 records in 1,395 connected groups. Category counts are 1,732 engineering, 235 agriculture, 253 humanities, 220 medicine, and 301 unspecified. The largest group has 54 records; actual splits are 2,228/284/229, not exact nominal percentages. Exact company keys do not resolve all subsidiary or semantic family aliases.

Arabic-number, supported-unit, and comparator checks reject some detectable translation changes but cannot certify all quantities or semantics. Scientifically equivalent reformatting can also trigger a conservative mismatch. Complete-parent English translations and expert-fit labels remain pending. It retains \PostRetained{} previous passes and downgrades \PostDowngraded{}; it does not promote earlier failures. Scientifically equivalent quantity reformatting and complete semantics remain outside its guarantee. Detection itself is incomplete and is not a semantic-quality label. \subsection{Budget and interface comparisons}
We additionally release a small temporal OpenAlex author-recovery proxy built from CC0 publication metadata: 867 historical works, 2,593 candidate author IDs, and 99 eligible held-out title queries. Five topical API searches and source/response hashes are recorded. Exact matches and high character-four-gram-overlap historical titles are excluded using a threshold chosen after inspecting a preliminary snapshot; semantic leakage and author disambiguation remain unaudited. Only target-paper authors with historical evidence are known positives; other candidates are unjudged, and 792 target works without an eligible author are excluded. BM25-max and BM25-vote recover at least one known author in 21 and 27 of 99 queries, respectively. This is a reproducible public proxy, not enterprise expert-fit, individual contribution or full-corpus recall. A separate rotating-order retrieval comparison on the same 99 queries gives 20/99 hits for candidate language-model ranking with selective evidence lookup, compared with 27/99 for BM25-vote. Mean one-shot times are 0.81 and 5.77 milliseconds respectively, excluding initialization and model reasoning; candidate index construction adds 0.18 seconds after a shared 0.04-second lexical build. This small proxy indicates a speed--recovery trade-off, not quality equivalence or scalable end-to-end latency. A later post-hoc control reranks the top 50 candidate-LM authors by the sum of up to five BM25 evidence scores: 25/99 hits and known-author recall 0.242, versus 27/99 and 0.256 for precomputed BM25-vote. Precomputed and ordinary BM25-vote have identical ordered top-ten lists for all 99 queries. Their mean one-shot retrieval times are 1.22 and 2.34 milliseconds, respectively, excluding initialization, construction, and model calls. These are development observations on reused data, not a held-out speed--quality guarantee. A later candidate-reasoning revision requires an exact quote in each cited owned source and records offsets within the visible text. A four-query local integration pilot completed all calls and returned 12 quote-anchored results, with two known-author hits; mean query time was 12.69 seconds. This verifies localization and integration only, not source entailment, identity, personal credit, or a comparison with the earlier ID-only prompt. A same-model support auditor marks all 12 reasons unsupported, both using excerpts and full visible source text. This result is unreliable: in a later control with five simple supported and five unsupported examples under two choice orders, it marks all 20 unsupported, including all ten supported instances. The auditor cannot be used as an automatic correctness filter without further validation. A later 2-by-2 instruction and choice-set wording ablation on the same controls returns five supported, four uncertain and one unsupported for ten positive instances in its best arm, and marks all ten negative instances unsupported. Choice values and descriptions change together, so individual wording effects are not isolated. These post-hoc variants remain unsuitable for automatic filtering. On six new handcrafted template pairs, the revised Decisions choice set and explained Chat each recognize three of six supported controls. Decisions rejects the other three; Chat marks them uncertain. Decisions rejects all six unsupported controls, while Chat rejects five and leaves one uncertain. These dependent examples do not validate either auditor. A later atomic prompt omitting query and attribution constraints matches all 12 labels on these reused controls; a contemporaneous scoped prompt matches 11. The scoped positive count changes across runs and slight prompt differences. Atomic entailment does not establish demand relevance or personal contribution, and these post-hoc results do not validate filtering. A same-model exploratory decomposition of 12 prior recommendations extracts 44 exact reason substrings: 17 source facts, eight transfer inferences, one personal-role claim and 18 others. Against cited excerpts, three source facts receive yes and 14 no; repeating the same claims with full visible source changes six of 17 judgments. The native atomic question matches all 12 reused simple controls, but decomposition completeness, batch behavior, transfer and personal attribution are unverified. A literal coverage check finds that extracted substrings cover 94.9\% of non-punctuation, non-whitespace characters overall, but fully cover only two of 12 reasons; the subset categorized as source facts covers 45.6\%. This character statistic does not establish semantic coverage or correctness. A stage audit finds at least one known author in 31 top-50 shortlists and 25 reranked top tens; four of the 27 full-BM25-hit queries have no known author in the shortlist, while two shortlist-reranked hits are full-BM25 misses. Comparisons are at query level and may involve different known authors.

The empty result has zero gain before completion, and later snapshots replace earlier ones even after a regression. This is an ordinary area-under-curve application, not a new metric theorem. Bounds address unjudged positions conditional on the supplied labels; they do not capture sampling uncertainty, annotator error, or actual expert ability. Focused and full return 20 and 18 completed results by the deadline, respectively. The horizon was chosen after observing the run, retrieval and initialization are excluded, and the labels are incomplete same-model silver; neither interval establishes an accuracy difference. Compare systems at the same horizon and report quality, completion and latency separately. No independently labeled enterprise result is available for this summary. On all 80 development needs, Qwen paper-max versus BM25-max has shared-label bounds $[-0.241,0.295]$; 50 high-impact unjudged views have been packaged for blind review, with no human labels yet. A later full-need retrieval-only audit averages 58.6 ms for candidate-LM evidence lookup and 254.7 ms for adaptive candidate-50 scoring; these single observations exclude initialization and reasoning. A paired later run accumulates only candidate scores during global scans and preserves all 80 results, averaging 233.3 versus 197.8 ms. An optional resident sorted-postings index preserves all 80 results and averages 16.2 versus 213.7 ms in a separate paired replay; building it takes 16.8 seconds and its numeric arrays occupy 104.8 MB, excluding dictionary overhead. It fails closed on observed external database changes. In four later sequential live calls, all first events arrive but three explanations time out and one returns four of five requested results; no independent quality labels exist. In a four-need agent pilot, the same-prompt arms each succeed three times and time out once; mean attempt times are 25.83 and 25.84 seconds, with initialization excluded. A reusable progressive implementation subsequently passes a one-need live smoke test; this does not establish accuracy or reliability.

As an exploratory implementation check on 73 public SIGIR reviewer-matching queries, a post-hoc 30-second horizon yields mean integrated soft/hard gains of 0.209/0.099 for full evidence, 0.381/0.183 for similarity packing and 0.340/0.155 for coverage packing. On 40 other cited abstracts without recorded evidence annotations, the model returns unknown 33 times, support twice and contradiction five times. Unannotated does not mean verified unsupported; all 40 await independent review. \paragraph{Profile-size exposure diagnostic.}
On 73 reused CoF SIGIR queries, reviewers have a median of seven distinct indexed profile papers. Profiles above this median constitute 41.8\% of the reviewer pool but 63.3\% and 64.1\% of lexical and dense top-five selections, respectively; the dense-minus-lexical query-bootstrap interval is $[-5.2,6.6]$ percentage points. Across all reviewer--query pairs, above-median versus other profiles have soft positive rates 37.2\% versus 39.6\% and hard rates 16.3\% versus 17.3\%. These pooled labels are dependent and do not control topic, query, or evidence quality. This post-hoc association is not a causal volume-bias estimate and does not establish individual contribution or justify a ranking penalty.

\paragraph{Random source-cap intervention.}
For each of 20 fixed seeds, we retain at most seven randomly selected papers per reviewer, consistently across 73 reused CoF SIGIR queries, and recompute dense max-source rankings from precomputed full-corpus scores. The fraction of top-five reviewers whose original profiles exceed the median decreases from 0.641 to 0.496. Seed-averaged soft P@5 changes from 0.425 to 0.424 (paired query interval $[-0.026,0.027]$); hard P@5 changes from 0.203 to 0.175 (interval $[-0.048,-0.007]$). The cap is post hoc; query intervals omit seed uncertainty and shared-reviewer dependence. Reviewer labels do not verify retained-source support. Random truncation can remove relevant evidence and establishes neither a fairness correction nor retrieval acceleration, as full-corpus scores were already computed.

\paragraph{Diversity-based source cap.}
A query-independent alternative starts from a source nearest the profile centroid and repeatedly selects the farthest source from the existing set, up to seven per reviewer. On the same reused reviewer queries, soft/hard P@5 is 0.430/0.175, compared with 0.424/0.175 for the seed-averaged random cap and 0.425/0.203 for all sources. Paired query intervals for diverse minus random are $[-0.022,0.034]$ and $[-0.020,0.022]$; these establish neither improvement nor equivalence. The method can favor outliers, source support is unjudged, and selection and evaluation are exploratory. All source scores were precomputed, so no online speedup is established.

\paragraph{Review-sample dependence.}
The 100-case intent/status-stratified human-review packet contains 96 parent needs and 96 company/body/URL groups; seven cases belong to three repeated groups, each spanning multiple strata. The packet contains no completed human judgments. Future uncertainty estimates must preserve sampling weights and shared groups across strata; independently resampling cases or strata ignores this dependence. The existing groups do not capture all possible topical or author dependence.

\paragraph{Query-level evidence coverage regressions.}
On the 293 reused EvidenceBench test queries, the role-prioritized selection increases annotated aspect coverage on 108 queries, leaves it unchanged on 156 and reduces it on 29; only 14 selections retain the same sentence set as the baseline. Seven of 28 queries with complete baseline coverage lose coverage. These model-assisted annotations are not enterprise expert-fit gold. The subgroups are post hoc and subject to floor and ceiling effects; a safe inference-time guard would require independent selection and held-out validation without access to aspect labels.

\paragraph{Exploratory simulated feedback routing.}
To connect the existing retrieval system to a feedback-driven research direction, we replay its frozen CoF SIGIR rankings with an epsilon-greedy choice between lexical and dense arms. Only the chosen arm's soft reviewer P@5 is revealed after each query. Across 30 overlapping shuffled streams, mean post-warmup soft P@5 is 0.412 for routing, 0.399 for fixed lexical, and 0.429 for fixed dense; routing chooses dense 58.7\% of the time. The data and streams were previously examined and are neither independent nor chronological. Reviewer labels simulate feedback; no user interaction, true enterprise fit, latency, training cost, old-task retention, or transfer is measured. This is a development sanity check, not evidence of continual improvement.

\paragraph{Cost-sensitive feedback replay.}
A subsequent exploratory replay uses the separately recorded live-query encoding and retrieval times for the same reused CoF queries. The chosen arm receives its soft reviewer P@5 minus an arbitrary hypothetical penalty of five P@5 units per second. Across 30 overlapping post-warmup streams, routing, fixed lexical and fixed dense average P@5 0.417, 0.399 and 0.427, with recorded component times 10.49, 20.87 and 8.16 ms. These are GPU-dense versus CPU-lexical component times from one prior measurement per query; full-agent, feedback and training costs are excluded. Reviewer labels simulate feedback and no chronological or held-out continual evaluation is performed. The penalty is not calibrated user utility or monetary cost.

\paragraph{Disjoint-fold feedback sanity check.}
A post-hoc split of the same 73 public reviewer queries separates 20 old-task, 20 simulated-feedback and 33 new-task cases after exact normalized query-text grouping. The update policy receives only chosen-arm feedback. Lexical starts at old/new P@5 0.400/0.376; after five updates the global policy selects dense and remains there through 20, giving 0.480/0.376, identical to fixed dense. This is not evidence of improvement over a strong baseline or generalizable continual learning. The data were already explored, time order is artificial, feedback is simulated, and recorded component times compare different hardware; no full-agent cost or independent enterprise assessment is available.

\paragraph{Sparse contextual feedback sanity check.}
A post-hoc variant of the same split keeps separate two-arm policies above and below 200 query tokens. After five simulated feedback updates, the short bucket has no feedback and defaults to lexical, while the long bucket selects dense; old/new P@5 is 0.420/0.339 versus 0.480/0.376 for fixed dense. After 20 updates both buckets select dense. The token threshold was chosen after inspecting data and is not a validated difficulty measure. This single reused split, simulated feedback, and artificial cost cannot support causal or generalizable claims; the result motivates explicit cold-start and sparse-feedback evaluations.

\paragraph{Incumbent guard under sparse feedback.}
An experimental router retains a fixed incumbent until each arm has three outcomes in a context. On the same post-hoc split, selecting dense as incumbent leaves both buckets on dense at all three checkpoints, because lexical has only one observed outcome per bucket. Old/new P@5 remains 0.480/0.376, exactly the fixed dense baseline. The incumbent and threshold were chosen after data inspection; this no-switch result neither establishes a statistical safety guarantee nor demonstrates learning. Feedback is simulated and selection bias remains.

\paragraph{Exposure-linked simulated feedback.}
An experimental in-memory registry associates each outcome with one selected action and its logged propensity, rejects conflicting duplicates, and leaves missing outcomes pending. Applied to the same simulated 20-update replay, it records all 20 exposures and outcomes and reproduces the guarded checkpoints. Deterministic actions lack policy overlap; logging propensity does not itself remove selection bias or establish off-policy validity. No real user feedback is present.

\paragraph{Logging support diagnostic.}
The simulated update replay records full action distributions. Two deterministic lexical actions assign zero probability to the fixed-dense target, so a conservative off-policy checker withholds its estimate. The checker also rejects missing outcomes and reports effective sample size when applicable. Logging support is necessary, not sufficient, for valid causal evaluation; propensity correctness, feedback missingness and confounding remain unresolved.

\paragraph{Weak-overlap estimator simulation.}
On 1,000 randomized action logs simulated from the same 73 frozen reviewer queries, the fixed-dense soft-label oracle is 0.422. When dense-action probability drops from 0.5 to 0.1, IPS root-mean-square error over draws increases from 0.056 to 0.166, while mean effective sample size falls from 36.42 to 7.34. The logs reuse the same data and use known action probabilities with complete simulated outcomes. This is a variance sanity check, not validation on real user feedback or industrial expert matching.

\paragraph{Cross-method annotation views.}
The legacy demand-pool exporter now deduplicates the sources actually returned per candidate by its three lexical baselines, removes source scores, and checks ownership and consistency. A four-query private development smoke test produced 87 candidate views and 256 source records. Experts and unreturned sources remain unjudged, identities can remain visible, and existing packets retain their original policy. No human relevance or source-support labels are implied.

\paragraph{Development-only dense and lexical review pool.}
A newly constructed private review packet unions five frozen dense, two random and five full-demand lexical candidates per development need. Across 80 reused queries it contains 948 candidate views, including 388 lexical positions outside the old pool, and 3,200 supplied source views. Source ownership and frozen spans are checked and method ordering is hidden, though text can reveal identities. All new judgments remain blank; prior fixed-view labels do not transfer automatically and unpooled experts remain unknown. Heldout queries are excluded.

\paragraph{Paired bounds for the joint review pool.}
For the fixed source-view conjunction of method fit and constraint support, shared unknown query/expert labels cancel between dense and lexical top-five lists. With all 948 joint-pool views still unjudged, the paired difference over 80 development needs is bounded by $[-0.9725,0.9725]$, with 778 unknown cells carrying nonzero coefficients. The interval is an identification bound, not a confidence interval, and cannot rank the methods. View-level lack of support is not expert inability.

\paragraph{Simulated correction-memory baseline.}
A development-only replay creates 16 templated reviewer suggestions from the 20 update queries and retrieves a previous suggestion by TF-IDF similarity for new queries. The template is not parsed; this tests candidate memory, not textual feedback understanding. On 20 old and 33 new reused queries, the baseline inserts a candidate 10 and 16 times. Soft P@5 changes positively on 1/5 queries and negatively on 0/2, respectively. These post-hoc results use self-ratings as simulated corrections, do not verify the proposed source for the new query, and establish neither safe transfer nor enterprise utility.

\paragraph{Correction identity permutation control.}
Permuting reviewer identities among the 16 fixed memory entries 1,000 times gives a mean new-query soft P@5 change of $-0.003$, compared with $+0.018$ for the original mapping; 85 permutations match or exceed the original. The original identities were selected using update-query labels, whereas permutation breaks that association. This is a post-hoc diagnostic on a reused cohort, not a causal significance test or independent evidence of safe transfer. Neither arm parses the feedback text or verifies source support for new queries.

\paragraph{Lexical gate for correction memory.}
A post-hoc gate keeps a memory-proposed reviewer only when its maximum BM25 paper score is positive and within the top 50 reviewer profiles. On 33 reused new queries, ungated/gated memory inserts 16/7 candidates; relative to fixed dense, reviewer P@5 improves on 5/2 and declines on 2/0. An extra full lexical scoring step averages 16.31 ms per attempted insertion on the local CPU; initialization and other stages are excluded. Lexical relevance is not verified source entailment or individual contribution, and this exploratory simulated-feedback comparison establishes no full-agent improvement.

\paragraph{Candidate-local lexical gate.}
A weaker gate checks whether any paper of the proposed reviewer has positive BM25 score, without global top-50 ranking. On 26 attempted insertions its per-source scores match the full scorer; on 33 reused new queries it admits all 16 insertions, including both reviewer P@5 decreases. The global gate admits seven. One sequential local-CPU measurement averages 0.444 ms for candidate scoring versus 15.63 ms for full scoring and owner ranking; resident index initialization is 89.37 ms and other agent stages are excluded. These gates make different decisions, so the timing contrast does not establish equivalent quality or source entailment.

\paragraph{Bound-based candidate gate.}
An exploratory gate computes the memory candidate's score, forms upward-rounded per-term reviewer upper bounds, and exactly scores potential competitors, retaining ties and expanding shared-paper ownership. It matches the global top-50 accept/reject decision on 26 reused attempts. For 16 new-query attempts, one sequential local-CPU measurement averages 6.27 ms versus 15.41 ms for full lexical scoring and ranking; an average 186.1 of 188 other reviewers still require scoring. Resident and bound construction take 91.49 and 32.03 ms separately. This is sample-level agreement, not a general numerical proof, semantic-support assessment, or end-to-end speed claim.

\paragraph{Shared-owner gate checks.}
The bound-based prototype is now implemented as a reusable component that rejects negative and nonfinite postings and expands shared sources across owners. Exhaustive small synthetic checks cover ties and shared ownership, including 50 randomized posting sets. A new replay reproduces all 26 prior full-gate decisions; 16 reused new-query attempts average 6.57 ms versus 16.06 ms for full lexical scoring and ranking, with one sequential, cache-sensitive observation per attempt. \paragraph{Five-candidate batched gate.}

\paragraph{Quality of the membership rule.}

\paragraph{Backfill diagnostic.}
On all 73 previously explored reviewer queries, placing candidates that pass lexical membership first and appending rejected dense candidates preserves the pool but changes the ranking. \paragraph{Open-weight decision pilot.}
