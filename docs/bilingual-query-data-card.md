# Bilingual query construction dataset

The local dataset is `artifacts/dataset-release/bilingual-query-construction-v1/`. It contains 1,000 complete original Chinese enterprise needs and 5,000 derived query intents with parallel Chinese/English text. Full English translations of the original needs remain pending. Parallel language views do not increase the independent-query count.

The five intent types are overview, component method, conditional transfer, evidence lookup, and constraint-focused search, with one generated slot per type and parent. Parents come only from the construction split of the new company/body/URL-grouped cohort. Validation and sealed groups were not used. Domain categories and source record hashes are retained for original queries; intent types describe generated requests rather than independently adjudicated labels.

Generation and native grounding/equivalence review use `gpt-6-luna`. All 1,000 parent jobs reached terminal records and all 5,000 slots contain generated text. The original screen retained 4,344 pairs. A separate conservative numeric postcheck retains 4,224 and downgrades 120; the final export retains all 776 unjudged pairs. There are **zero expert-fit labels**. Screened status does not establish human-verified semantic equivalence, relevance, or actual expert capability.

Version-2 numeric checking handles additional negated comparator aliases and abstains on unsupported nearby negation. Across all pairs it reports 4,400 numeric matches, 370 mismatches and 230 uncertain checks. A numeric match is insufficient for admission: the export intersects it with the previous grounding screen and never promotes a prior failure. Numeric-free pairs have no numeric evidence of equivalence. In the frozen 5,000-pair snapshot, 3,415 pairs have no detected numeric anchors in either view; 3,355 of the 4,224 retained pairs (79.4%) are in this category. Only 869 retained pairs have detected anchors in both views, and 576 have a detected comparator in each view. These are parser coverage counts, not estimates of semantic correctness; the parser can miss anchors. Run `PYTHONPATH=src python -m experiments.bilingual.audit_numeric_coverage` to reproduce the overall and intent-level counts. Source responses, the frozen original generator and its version-1 guard remain unchanged.

The construction screen has uneven coverage by intent: unjudged counts out of 1,000 are 115 component-method, 74 conditional-transfer, 279 constraint-focused, 212 evidence-lookup, and 96 overview. Five parents have no retained pairs, and 550 have all five retained. Among initially screened pairs, the later numeric guard downgraded eight mismatches and 112 uncertain cases. Thus filtering to retained pairs changes the type distribution and can hide hard constraints; report coverage by type and retain unresolved items as unknown. These counts describe the screening process, not measured error rates. Reproduce aggregate checks with `PYTHONPATH=src python -m experiments.bilingual.audit_screen_coverage` against the local frozen artifacts.

Rebuild locally after generation has completed:

```bash
PYTHONPATH=src python -m experiments.bilingual.postvalidate_queries
PYTHONPATH=src python -m experiments.bilingual.export_dataset
```

The exporter rejects changed source cohorts or parent records, incomplete parent coverage, missing postchecks, duplicate query slots, and protected-split entries. Each output has a SHA-256 manifest. Original enterprise text remains subject to its original access terms and is excluded from the public MIT software archive. This is a construction dataset, not a completed independently labeled expert-search benchmark.


A subsequent full-original translation pilot compares direct, copied-placeholder, and fixed-numeric-block gap translation on the same 32 construction parents. Combined native/limited-numeric screening retains 8, 6, and 3 records respectively; unresolved request/structure counts are 1, 9, and 8. The runs were sequential exploratory ablations, and screens are not human gold. No variant is adopted for translating all 1,000 original needs. The 5,000 derived bilingual requests remain a separate construction product.

A frozen retrieval diagnostic selects one derived query per original parent, cycling types to give 200 each: 860 retain the screen, 140 remain unjudged. Exact Chinese/English top-ten overlap is 42.16%; this is ranking stability, not relevance accuracy. HNSW floor512 retains99.805% of exact top-ten entries across2,000views but only1,962 ordered lists match. These results motivate further alignment and verification, not a claim of bilingual quality completion.

The original 2,741-need pool has 1,395 group IDs, with no group crossing construction, validation and sealed splits. Whitespace-stripped character four-gram Jaccard screening of 513 validation/sealed needs against construction gives maximum 0.329; no maximum reaches 0.5. This aggregate read-only diagnostic does not detect semantic paraphrases, shared organizations missed by grouping, or other leakage. The reproducible check is `experiments/bilingual/check_split_overlap.py`; protected examples remain unavailable for tuning.

A conservative release-readiness scan (`experiments.bilingual.audit_release_identifiers`) flags at least one tested literal in 22 English and 20 Chinese query views. These counts include organization-like suffixes and other literal indicators, not confirmed identities; three English views contain a tested Chinese organization suffix. A broader Unicode scan finds Han characters or radicals in 33 English views: 18 previously retained and 15 unjudged. Thus an English-only release needs additional handling even when the language field is present. These character checks do not resolve translated identifiers or distribution rights. No URL, email or seven-digit run matched these specific expressions. The checks do not detect all names, indirect identifiers, confidential facts, verbatim reuse or rights restrictions. They do not authorize release, and the generated pairs remain local pending source rights and appropriate review.

An additional parent-specific literal audit (`experiments.bilingual.audit_parent_reuse`) finds one Chinese view containing its full parent company field after case and whitespace normalization. It also finds exact 16-character parent runs in 1,073 Chinese and 45 English views, and 32-character runs in 39 and one respectively. Grounded rewriting can intentionally reuse technical phrases, and a text match alone does not resolve rights. The checks miss company-name variants, translated names, indirect identifiers and semantic paraphrases; neither an unmatched pair nor redaction by itself proves that publication is permitted. The scan supports a manual review and release-rights assessment before publishing any derived text.

The existing 100-case blind grounding review contains 43 cases with no detected anchors. Its evidence-lookup/unjudged stratum has 22 such population cases but none in its ten sampled cases. A separate, local targeted supplement draws five of these 22 cases using a fixed seed. It is not part of the original probability sample; do not combine it with the original weighted analysis without a revised sampling design. Neither packet has completed human judgments. Coverage and supplemental construction are reproduced with `experiments.bilingual.audit_review_numeric_coverage` and `experiments.bilingual.export_numeric_gap_review`; the latter refuses to overwrite an existing packet.

A separate non-numeric English control probes negation, object substitutions, conditions, and shifts from possible research to claimed achievements or guarantees. Eight handwritten templates each have an identical faithful request and a changed request; each is judged twice with reversed choice order. All 32 Decisions API calls returned the intended label. These simple, dependent English controls use the same model family as generation, lack realistic faithful paraphrases and Chinese evaluation, and do not estimate semantic accuracy on the 5,000 real-derived pairs. Reproduce with `PYTHONPATH=src python -m experiments.bilingual.semantic_scope_controls`; it creates a new local artifact directory and does not overwrite an existing run.

A follow-up replaces the identical faithful requests with handwritten English paraphrases, then separately uses Chinese faithful and changed requests against the English sources. Each cohort uses the same eight templates and two choice orders; both return their intended labels on all 32 calls. Runs are sequential and examples are hand-authored, dependent and easy to distinguish; the English-to-Chinese direction is only one direction and no real enterprise semantic accuracy follows. Run the same module with `--paraphrase` or `--cross-language` for the respective new cohort.

One of nine passes the same-model complete-translation audit plus the limited whole-text numeric guard; seven remain unjudged and one unresolved. A post-hoc analysis of the 1,000 construction pairs relates bilingual query-vector cosine to exact-index top-ten overlap. Pearson's correlation is 0.354 (2,000 company-group bootstrap replicates, percentile interval 0.295--0.406); the lowest and highest cosine quartiles have mean overlap 0.342 and 0.518. Even in the highest quartile, 7.6% of pairs have overlap at most 0.2. This descriptive relationship does not establish translation correctness or expert relevance, and requires both language views. Run `python -m experiments.bilingual.analyze_alignment_dependence` with the frozen local diagnostic inputs to reproduce it.

A separate public-label diagnostic translates the first 20 previously examined CoF SIGIR paper queries from English to Chinese using `gpt-6-luna`. Nineteen Chinese texts are available; one translation timed out. Of those 19, ten pass same-model equivalence and limited numeric checks, eight remain unjudged, and one has an unresolved audit. All 19 contain Han characters, which does not establish translation quality. Frozen Qwen3 query encoding runs on Slurm job 39586 on ws5, with no truncation; the original English reviewer labels are then used for both views. On the 19 pairs, mean soft P@5 is 0.421 for English and 0.442 for Chinese; hard P@5 is 0.168 and 0.189. The Chinese-minus-English query-bootstrap intervals are [-0.053, 0.084] and [-0.074, 0.105], respectively. Mean top-ten overlap is 0.747. Conditional on applying the original reviewer labels to translated queries, one missing translation remains unknown in the 20-query Chinese P@5 bounds: [0.420, 0.470] soft and [0.180, 0.230] hard. These reused public reviewer labels and same-model translation screens do not establish translation equivalence, industrial expert fit, or comparable full-agent latency.

Newly encoded English vectors have mean cosine 0.99985 and mean top-ten set overlap 0.984 with the prior cached English vectors, but only eight of 19 ordered top-ten lists match. The encodings were made in separate batches on different GPUs, so numerical drift and rank ties require care; no specific cause is established. Model load, query encoding, source-vector construction and reasoning are excluded from the cached scoring time. ## Backtranslation and rank fusion pilot

A follow-up on the same 20 previously explored CoF SIGIR queries evaluates direct Chinese retrieval, retrieval of a model backtranslation, and reciprocal-rank fusion (constant 60, full judged candidate lists). The model receives only the Chinese view, never the original English query or reviewer labels. Of 20 planned queries, 19 have both views; one remains missing. Nine of the 19 passed both same-model translation screens, which are not independent semantic judgments.

On the 19 available pairs, soft-label P@5 is 0.442 for Chinese, 0.411 for backtranslation, and 0.442 for fusion; hard-label P@5 is 0.189, 0.211, and 0.211 respectively. The paired fusion-minus-Chinese hard-label difference is 0.021 with an unadjusted 95% query bootstrap interval of [-0.032, 0.095]. The sample is reused and translations lack independent human validation; transferred reviewer labels therefore provide only conditional evidence. These findings do not establish a precision improvement or industrial expert fit.

Mean backtranslation time was 3.168 seconds for the 19 successful calls, excluding the audit. Encoding 38 views on an RTX 5090 in one batch took 0.283 seconds, excluding initialization; this is not single-request latency. The extra model call makes this pilot unsuitable as evidence of a faster end-to-end search. The earlier and newly encoded Chinese vectors have mean cosine similarity 0.999905 and mean top-10 overlap 0.979. Slurm job 39591 completed on ws5 with the checkpoint provenance pinned at encoding. Source texts and generated views remain local.

## Numeric provenance diagnostic

A new diagnostic compares normalized numeric values detected in each generated view with the cited parent segments and the complete original Chinese need. It separately flags values found only elsewhere in the parent and values absent from the entire parent. This is a value-presence check, not a hallucination or grounding label: the parser can miss spelled-out numbers or confuse identifiers with quantities, and it cannot establish units, conversions, arithmetic, scope, comparators or semantic support.

Across the 5,000 pairs, 30 have at least one detected value absent from the full parent in either view; one was previously retained by the same-model screen and 29 were unjudged. English views account for 30 flagged pairs, and one Chinese view is flagged. Relative to cited segments, three Chinese and 43 English views contain a detected value absent from the cited text, including values that occur elsewhere in the parent. These are review candidates, not measured error rates. The audit leaves source records and existing statuses unchanged.

A local blind packet includes all 30 full-parent flags and 30 numeric-bearing controls matched on intent and original screening status, shuffled with a fixed seed. It shows the original need, cited segments and both generated views, but hides audit group and original status. The targeted sample is not a population probability sample and may be recognizable from source content. All 180 grounding/equivalence fields remain unjudged. The source and review packet remain local. Reproduce with `experiments.bilingual.audit_numeric_provenance` and `experiments.bilingual.export_numeric_provenance_review`; validate a reviewer copy using the existing `experiments.bilingual.check_grounding_review` command. The audit does not establish publication rights or anonymization.

A follow-up applies the same `gpt-6-luna` family to the 60-case blinded packet, asking separately whether numerical values, units, objects and relations in each language are directly supported by the complete parent. The model receives neither audit group nor previous screening status; both query languages are present in the request, so cross-language contamination remains possible. All 60 calls returned valid choices. In the 30 numeric-flagged cases, 11 have at least one language judged changed or unsupported; in the 30 matched controls, 13 do. At least one language is uncertain in 11 flagged and eight control cases. The single flagged case retained by the earlier screen receives supported for both languages in this additional model judgment.

These are not error rates, calibrated confidence or independent validation: the controls are targeted and matched rather than population-random, the same model family generated the data, and the question is broader than the value-presence heuristic. The apparent group difference cannot establish which method is right. None of the existing statuses was changed; the 180 human review fields remain missing. Use `experiments.bilingual.audit_numeric_provenance_decisions` with the local packet and a new output directory to repeat the 60 paid model calls. Source text and case-level outputs remain local.

A versioned recheck investigates spaced signs without changing the original parser or dataset. It detects a possible negative-value interpretation when a minus or dash is separated from digits by whitespace. Because the same typography can denote a range or bullet, this is explicitly **ambiguous**, not verified numeric support. The recheck exactly reproduces the original 30 flagged pairs; one has a possible spaced-sign match in both languages, and the other 29 still contain a value absent under both interpretations. The ambiguous pair is the only one previously retained by the model screen; the other 29 remain unjudged. Original flags, reviews and statuses are preserved, and none of these counts establishes semantic correctness or an error rate. Run `experiments.bilingual.audit_numeric_spaced_sign` against the frozen audit to reproduce the counts.
