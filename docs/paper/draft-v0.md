# 面向产业专家搜索的约束证据复用与预算化判定

**研究初稿 v0：方法假设尚待验证；不作已获性能提升或原创性确认的声明。**

## 摘要

产业专家搜索要求将企业需求映射到专家的技术能力，并提供可核查的成果证据。逐候选生成式推理会增加延迟，纯相似性排序则难以区分必要条件缺失和术语近似。本文探索无需训练的约束证据检索路线：离线组织带来源的能力证据，在线仅判定可能改变候选排名的未解决约束，并将证据判定复用于多次需求匹配。我们设计双向证据约束合成流程及限时证据满足评测协议。现有基线实验表明，直接加入树导航并未显著提高准确率：10 条作者恢复查询上，树 agent 与 BM25-vote 的 nDCG@10 分别为 0.5551 和 0.5675；该结果仅用于诊断。新路线的真实精度与延迟实验尚未完成。

## 1 引言

真实产业需求往往同时要求技术方法、目标对象、部署条件与应用场景。某位专家与主题相近，不意味着已有资料支持全部必要能力。另一方面，资料缺失也不等于能力不存在。因此搜索结果需要区分支持、明确矛盾和未知，同时控制检索与模型判定成本。

本研究的目标不是让所有查询经过更长的推理，而是降低构成可靠匹配所需的新增证据判断数量。拟验证三项贡献：（1）能力证据复用和增量判定方法；（2）有来源的反事实合成数据构造；（3）考虑必要约束、证据真实性及时间预算的评价协议。它们目前均为候选贡献，不能据此宣称首次提出。

## 2 相关工作与差异

专家检索的候选模型、文档聚合及投票已有系统研究（Balog et al., 2012）。RAPTOR 的摘要树、PageIndex 的模型树导航和 HippoRAG 2 的图关联表明结构索引本身不新。LiteRAG 已用算法图遍历减少在线模型控制；AURA 学习自适应推理深度。我们的约束是不训练模型，潜在差异在于将在线判断单位改为可复用的需求约束—原文证据对，但其新颖性仍需全文查重。

上下界 top-k 聚合与 Fagin–Lotem–Naor 阈值算法相关，本文不将一般停止规则作为新定理。Time-Biased Gain 和 alpha-nDCG 已分别考虑时间及多方面覆盖，新评测必须证明必要条件的联合满足及来源真实性提供了额外信息。

## 3 问题定义

给定需求 q、专家集 E 和带来源证据 D，解析约束 C(q)，标记必要或可选。每条证据对约束的判定属于支持、矛盾或未知。模型概率只作评分输入，不解释为事实概率。任务输出有序专家、引用和未解决约束，并记录首次排名与完整解释的可见时间。

固定候选集内定义归一化非负权重 w_j 与固定判定分数 s_ej∈[0,1]，S(e)=Σ_j w_j s_ej。该可加函数用于算法验证，不等同于必要约束全部满足。必要条件的联合匹配另外评估，不能通过多个可选条件补偿。

## 4 方法：待验证设计

离线提取保留原文跨度的能力原子，建立能力—证据—专家映射。规范化后的能力仍需保留原始术语、场景和条件，避免错误合并。在线进行词法与冻结语义检索，按需求约束选择证据，维护候选分数上下界。模型判断以批处理方式执行，优先处理可能改变排名的未知单元。

若部分分数已确定，下界为已判定贡献，上界再加所有未知项的最大贡献。第 k 名候选下界严格超过其余候选上界时，可证明固定候选集内 top-k 成员集合已确定。此证书不保证内部顺序、不保证全库召回，也不保证判定器正确。预算耗尽时返回未认证结果。

Decisions API 和普通结构化输出作为可替换执行器；比较相同后端的全量判定、增量调度和批量大小，才能区分产品速度与算法增益。缓存键需包含约束语义、证据内容哈希、判定器版本和提示版本；改写之间不可仅凭词向量近似直接共享结论。

## 5 数据构造

真实企业需求提供任务分布，真实教师成果提供可验证能力边界。先按需求族、专家、重复成果分组划分，再生成改写。构造支持条件、部分满足条件及最小改变的反事实条件。未观察到的能力只标未知。引用跨度必须可精确回溯；反事实改变只保证文本操作可控，不能自动保证真实语义标签。

采用独立验证和分歧保留，不把同一模型自评当 gold。当前小样本试验仅做来源跨度验证，语义核验仍待完成。公开数据需核查再分发许可，受限语料提供获取脚本和校验值。

## 6 评测协议

传统指标保留 nDCG、MRR、Recall。新增协议拟测量：必要条件有证据支持比例、错误支持率、未知率及随时间变化的匹配质量。以受控反事实检验遗漏必要条件、重复证据、无支持引用与延迟的惩罚响应。避免用未经论证的任意权重合成单一总分。

效率报告冷/热启动 p50/p95、吞吐、token、判定单元数、离线索引成本和查询量摊销。所有方法同硬件、同模型后端、同候选及证据预算；另外测全库召回。公开真实标签数据与合成数据分开汇报。

## 7 当前结果及限制

现有 30 查询作者恢复基线 nDCG@10：BM25-max 0.3848、BM25-vote 0.4052、TF-IDF 变体 0.3274。同一前 10 查询上，树 agent 0.5551，BM25-vote 0.5675，差值 95% bootstrap 区间 [-0.2631,0.2339]；平均耗时分别 16.451 和 1.436 秒。这不是新路线结果，也不能代表真实需求匹配。

随机有界分数模拟中，40 候选、8 约束、k=5 的增量判定平均仍需 81.38% 单元，说明仅靠上下界早停难以实现极致效率。100 个随机对照测试验证 top-k 成员与穷举一致，不构成实际搜索准确率证据。

## 8 结论与待完成项

当前证据否定了“加入树 agent 即可同时提速提准”的简单路线。下一阶段重点是证据复用是否能减少判定工作量，以及该复用是否保持条件和来源的正确性。待完成独立数据验证、强语义基线、公共数据适配、真实延迟实验和指标有效性检验。实验未完成前，不填写预期提升数字，不将本稿作为可投稿完成稿。

### 研究原则补充

本研究保留已知但有效的算法组件，并明确引用；不以“每个模块全新”为目标。后续贡献判断基于组合机制是否解决产业专家搜索的特定困难，以及公平消融是否证明其价值。目前 3 条合成试样均通过原文跨度检查，但未验证语义标签，不能作为数据质量结论。

### 独立公开标签组件验证

SciFact BEIR 版本 300 查询：优化 BM25 nDCG@10=0.6605、Recall@10=0.7876，热进程顺序查询 p50/p95 约 19.2/34.3ms；TF-IDF 变体 nDCG@10=0.6527。它们是独立标签的检索基线结果，尚未评估本文拟议组合方法，不能推导专家推荐质量。

### 首次组合原型的负结果

固定约束与五候选的单例对照中，文档核验约 19.4 秒，片段核验约 21.2 秒，均为 40 个判断对、两次请求。片段输入为 3,950 字符，但未带来观察到的净核验加速；总耗时不可直接比较，因为片段版复用了解析结果。两版返回候选支持覆盖均为零，无法证明精度增益。后续实验必须改善证据召回和数据构造，而非只压缩输入。

### 证据优先合成试验

十条真实需求驱动的尝试中，三条因证据不足在生成阶段被拒绝；其余经异模型盲核验后，仅三条满足当前跨度与一致性筛选。30% 的试验保留率说明生成质量不能由提示要求保证。保留样本仍是 silver，反事实标签、完整查询匹配和领域代表性尚未充分核验。

### 独立专家标签验证起点

CMU Gold 的 d_20_1 标准档案版本上，最大论文 TF-IDF 余弦基线的加权配对损失为 0.2784071（1,653 个非同分配对），与原作者评分实现完全一致。此处衡量同一专家对已评分论文的顺序，不将未评分对象当负例；尚未进行十档案版本复现及新方法比较。

### 指标构造有效性检查

在十项等权约束中设置两项必要条件：缺失一个必要条件和缺失一个可选条件的传统覆盖均为 0.9，但必要条件门控分别为 0 和 0.9。该受控例说明协议能表达不可补偿要求；不构成真实用户偏好验证。必须继续报告未知率，避免把资料稀疏专家简单判为能力不足。

### 冻结画像组合实测

CMU Gold d_20_1，text-embedding-3-small：最强论文损失 0.25447，平均画像 0.24209，固定各半混合 0.23531。混合减最强论文差为 -0.01915，按研究者配对 bootstrap 的 95% 区间 [-0.04588, 0.00671]，不能宣称显著优势。上界保持最强论文评分不变，但成员点积 6,362 加上界点积 1,877，多于穷举 6,971；该规模下无计算量收益。

### 数据构造失败分析

三条通过逐约束和跨度筛选的样本，在完整查询审核中全部含未经支持的领域限定或能力组合。当前不能将其称为完整有效正例。已启动反馈修正：删除不被证据支持的条件、保留较窄任务，再独立复核；原始失败样本完整保留。数据质量需以完整任务语义为单位，不能只统计原文引用成功率。

### 固定预算证据核验的初步信号

CMU 按 reviewer ID 排序前十位、220 个可比较配对：统一标准模型评分（每目标论文三篇相关证据）损失为 0.19027；同子集词法 0.32019、最大论文向量 0.25342、平均画像 0.21802、固定混合 0.22446。所有十次请求成功，平均每位研究者调用耗时 9.74 秒，不含离线向量编码。该结果来自小型非随机子集，正在扩展全 58 位，不能提前称为显著提升或效率优势。模型评分和真实标签隔离，但预训练污染与评分标准差异仍需讨论。

### 渐进检索的局部 Pareto 信号

SciFact 300 查询、预计算查询向量、单 BLAS 线程、预热后交替三次重复：完整向量检索均值 0.751ms、p95 1.395ms；256 维筛选＋100 候选完整精排均值 0.318ms、p95 0.581ms，检索计算阶段约 2.36 倍平均提速。两者 nDCG@10=0.72605、Recall@10=0.85489。900 次对照中 759 次前十完全一致，说明指标相同不等于排名完全一致。索引额外构建约 5.56ms；应进一步报告额外存储、在线编码、规模增长和新查询泛化。该机制是成熟多分辨率检索的实例，局部收益不能解释为完整 agent 同倍提速。
