# Evidence-Preserving Multiresolution Expert Search without Model Training

**中文研究初稿 v1。目标会议：SIGIR / WWW。尚未证明完整方法同时优于强基线的精度与端到端效率，贡献措辞为研究假设。**

## 摘要

产业专家搜索要求在技术需求与专家成果之间建立可核查的匹配。现有生成式搜索增加在线推理开销，而相似性检索难以表达必要条件缺失与资料未知。本文研究无需训练的证据保真多分辨率检索：以原始成果、专家平均画像和来源化能力卡组成离线索引，在线通过低维筛选、完整向量精排及有限证据核验返回专家。配套设计从真实需求和专家证据构造任务的生成—审核—修正流程，以及必要约束门控的限时评价协议。SciFact 300 查询上，渐进检索保持 nDCG@10=0.7261，本地检索均值从 0.751ms 降至 0.318ms；该收益不含网络编码。CMU Gold 58 位专家上，固定画像混合损失为 0.2353，能力卡未进一步改善。在线核验初步显示小样本精度潜力，但尚需完整结果和独立验证。数据试验表明，仅核验引用与原子约束不足以保证完整任务正确，严格筛选后样本规模仍不足。

## 1 引言

企业需求通常组合技术、对象、场景与约束。描述相近并不保证专家资料支持全部必要能力；资料未提及某能力也不等于该专家不具备能力。因此专家搜索需要同时返回排序、支持证据及未解决条件。

本文以“新增在线工作量”而非推理文本长度为优化对象：将可复用信息前移至离线索引，快速完成候选排序，仅在必要时核验来源。我们保留已有有效组件，不要求每一模块原创。拟验证贡献是：（1）证据保真的多分辨率索引与预算化核验组合；（2）完整任务语义约束的合成审核修复流程；（3）区分必要条件、未知与限时结果的评价协议。当前研究阶段并未证实三项均达到投稿所需证据强度。

## 2 相关工作

专家检索已有候选模型、文档模型、投票与画像聚合。Feng 等的产业专家语义树已结合离线 LLM 解析、概念归一化和成果聚合，与本任务直接相关。RAPTOR、PageIndex 和 HippoRAG 2 说明树与图组织可帮助证据检索；LiteRAG 已将模型移出检索控制循环。AURA 则使用学习式效用估计器自适应控制推理深度，与本文不训练的约束不同。

本文不把层次索引、摘要、缓存、批处理、几何上界或低维筛选单独称为原创。潜在差异在于专家需求条件的证据状态、多分辨率表示与核验调度的组合，并以实测和消融判定价值。指标需与 alpha-nDCG、Time-Biased Gain 等区分，不能把覆盖与时间折扣的改写当作新理论。引用元数据见 references.bib，近邻方法全文审查见 ../exploration/closest-work-review.md。

## 3 任务与证据状态

输入需求 q、专家集 E、带来源成果 D。每位专家 e 的证据 D_e 保留原始 ID、位置和内容哈希。需求约束 C(q) 包含必要条件与可选条件。证据状态为 supported、contradicted、unknown；未知仅表示当前证据不足。模型输出概率或分数不作为真实能力的校准概率。

输出包括专家排序、引用、未解决约束、结果可见时间。排名首次可见与完整解释完成分开计时。候选遗漏、证据选择失误和判定失误分别统计。

## 4 方法

### 4.1 离线来源保真表示

为每位专家维护三类表示：原始成果向量、归一化平均画像、模型生成能力卡。卡片包含技术内容及原文引用，只允许单篇来源支持，避免无依据的跨论文应用拼接。引用不匹配时拒绝卡片并回退原始画像，不从测试集删除专家。卡片作为检索摘要，不自动构成真实能力标签。

### 4.2 多分辨率候选检索

对冻结向量的低维前缀作归一化并预存，用其筛选候选，再以完整向量精排。当前固定 256 维、100 候选、返回 10 项。该近似策略必须实测召回损失，不提供全库正确性证书。排序采用固定规则；融合权重不按测试标签优化。

### 4.3 证据选择与预算化核验

原文按句段建立带字符偏移的索引，以需求约束检索相关证据。模型按批判定约束—证据对，缓存键包含证据内容、约束、模型和提示版本。精确重复可复用结果，语义近似改写不直接共享结论。

对于固定评分器的可加分数，未知贡献在 [0,1]，可维护分数上下界并判定候选集内 top-k 成员是否确定。这是已有上界聚合思想，仅约束算法评分，不保证事实真实性、内部完整顺序或全库召回。当前自适应核验与所有索引组件尚未完成统一实证闭环。

## 5 合成数据：生成、审核与修正

真实需求提供任务分布，教师资料提供能力边界。构造时先选择同一专家可追溯证据，再形成任务和原子条件。加入只改变一项条件的反事实需求，区分明确矛盾与缺少支持。

审核分三层：原文引用跨度检查；隐藏生成标签的异模型原子约束审核；完整查询及反事实审核。第三层检查应用场景、修饰语和能力组合中的额外要求。发现不支持内容后修窄任务并重新审核，保存失败原件。模型一致仍只产生 silver 标签。

按专家、需求族和重复来源连接分组后划分集合，防止改写泄漏。发布材料保留来源哈希与标签来源；原始资料按各自许可处理。当前二十次试验与修正流程仅形成一条严格候选，不能声称完成高质量大规模数据集。

## 6 评价协议

传统指标保留 nDCG、MRR、Recall 和 CMU 官方加权配对损失。新增协议记录：（1）带有效证据的条件覆盖；（2）必要条件联合满足；（3）未知与错误支持；（4）deadline 下最新结果质量，而非历史最佳质量。

受控例中，遗漏必要或可选条件均可有 0.9 覆盖，但必要门控分别为 0 与 0.9，表达不可补偿约束。这只证明构造行为，尚需验证与独立人工效用的一致性。效率同时报告冷/热启动、p50/p95、QPS、token、离线成本及摊销；语料与查询向量预计算不能被隐藏。

## 7 实验

### 7.1 数据与基线

本地含 10,673 位专家与 54,409 篇论文。SciFact 使用 5,183 篇文档、300 条测试查询，仅验证检索组件。CMU Gold 含 58 位研究者、477 条评分，比较同一专家的已评分论文，不把未评分对象当负例。当前使用 d_20_1，尚非十档案复现。

基线包括优化 BM25、TF-IDF 变体、冻结 dense、RRF、最强论文、平均画像、固定混合、能力卡及固定三篇证据模型评分。所有模型不在本研究中训练。

### 7.2 已完成结果

| 任务 | 方法 | 指标 |
|---|---|---:|
| SciFact | BM25 | nDCG@10 0.6605 |
| SciFact | 完整冻结向量 | 0.7261 |
| SciFact | RRF | 0.7246 |
| SciFact | 256维筛选＋完整精排 | 0.7261 |
| CMU Gold | 词法画像 | 配对损失 0.2784 |
| CMU Gold | 最强论文 | 0.2545 |
| CMU Gold | 平均画像 | 0.2421 |
| CMU Gold | 固定混合 | 0.2353 |
| CMU Gold | 能力卡 | 0.2656 |
| CMU Gold | 卡片＋原始混合 | 0.2375 |

CMU 固定混合相对最强论文差值 -0.01915，研究者级 bootstrap 95% 区间 [-0.04588,0.00671]。不宣称显著优势。模型三证据评分全量 57/58 请求成功；一次格式失败按全同分预测计入后，损失 0.24156，未超过固定画像混合。成功请求平均调用约 10.75 秒。前十位子集上的优势未稳定延续。

### 7.3 效率与负结果

SciFact 单线程本地计算三次交替重复：完整向量均值 0.751ms、p95 1.395ms；渐进检索均值 0.318ms、p95 0.581ms。900 次中 759 次前十完全相同，指标相同并不代表排名完全相同。五条真实网络查询中编码约 0.52–1.40 秒，网络仍占主导。本地冻结 ONNX 编码器正在验证。

几何球上界保持最强论文分数，但该规模上总点积开销增加。短句段判定没有观察到净加速。简单画像分歧路由回放减少请求却损失精度。能力卡尚未优于原始画像混合。这些失败说明仅叠加结构或缩短文本不足以实现目标。

## 8 局限与后续实验

核心缺口包括：完整组合方法的线上测试、规模化高质量合成数据、独立领域标签、指标效用验证、多档案及多数据集稳定性。CMU 自评不等于企业项目履约能力，公开模型可能存在预训练污染。单机与单服务测量不能外推到生产 SLA。

下一阶段保留已验证的快速检索组件，检验冻结本地编码与有限核验是否能形成端到端 Pareto 改善；数据构造需以完整任务审核为门槛。未获得证据前，不写“远超其他方法”的结论。

## 9 结论

当前探索建立了可复现的检索、专家匹配与数据审核实验，验证渐进检索的局部效率收益，并发现生成式核验、摘要索引和数据构造中的关键失败模式。本文尚是一份研究初稿，完整三项贡献仍需实证支撑。

### 条件组合的可核查诊断

另外构造 500 条明确原词条条件组合任务，逐条对原始教师记录核验完整与部分匹配集合及来源位置。BM25-max nDCG@10=0.9864，BM25-vote=0.7921；显式集合交集参考为 1.0000。参考算法与任务语法高度一致，任务也偏容易，结果只能验证条件联合匹配诊断，不能替代企业需求语义测试或作为主性能优势。

### 本地编码可行性探测

冻结 BAAI/bge-small-en-v1.5 在 20 条预热查询上，单 ONNX 线程编码 p50=5.70ms、p95=9.34ms；模型加载约 107ms。本次有并发后台实验，仅作可行性探测。它与 API 的 text-embedding-3-small 不是同一模型，尚未完成全语料精度测量，不能将这组延迟与 API 模型 nDCG 拼接为同一系统结果。

### 语义条件诊断扩展

对 50 条来源化双条件作模型改写与异模型双向等价审核，49 条通过、1 条因范围变化被拒绝。仅按已知来源恢复计算，BM25-max nDCG@10=0.9312、Recall@10=0.9388，TF-IDF 变体 nDCG@10=0.9388。由于标签不完整且难度仍低，这些数值不能解释为真实专家匹配准确率，也不足以支撑强推理需求。导出数据保留来源引用、分组与哈希，移除原文及模型 trace；它是单独的语义条件诊断层。

### 本地完整路径结果

冻结 BGE-small-en-v1.5 在同一 SciFact 300 查询上 nDCG@10=0.72011、Recall@10=0.84522，查询编码＋精确向量检索 p50=5.40ms、p95=9.23ms；不含首次模型下载/初始化与离线语料编码。相比 API 模型 0.72605，质量差约 0.00595，尚需配对区间验证，不能称为无损。网络 API 仅五条计时探测，不能据此报告严格全量倍数加速。固定本地 BGE＋BM25 RRF 正在运行以检验质量补偿。

### 固定融合与中文迁移

本地 BGE＋BM25 RRF 在 SciFact 上 nDCG@10=0.71272、编码至融合 p50=26.41ms、p95=44.46ms，低于单独 BGE 的质量且更慢。固定融合不能被默认当作增益。

中文研究方向去重为 19,174 个概念，冻结 BGE-small-zh 编码构建约 14.25 秒（不含模型下载）。49 条语义条件诊断上，最大概念相似度的已知来源恢复 nDCG@10=0.71141、Recall@10=0.86395，查询编码＋概念/专家检索 p50=3.15ms、p95=4.23ms。词法已知来源恢复约 0.93，说明快速概念路径仍丢失联合条件，不能称为精度改进。该实验只是来源恢复，不是企业任务 gold。

### 相对排序与字段索引对照

CMU 全 58 位的同证据相对排序全部返回合法排列，加权损失 0.23240，略低于固定画像混合 0.23531；该微小差异仍需配对区间，不能宣称稳定优势。前三位各一次正序/反序中 48 个配对有 6 个预测顺序改变，混合了展示顺序与模型随机性。

49 条语义条件诊断上，研究方向专用、预计算倒排 BM25 的已知来源恢复 nDCG@10=0.93878，查询 p50 约 0.110ms；二元组 IDF 覆盖基线约 0.082ms，nDCG@10=0.93124。它们是精简字段索引基线，不是新模型，也不代表完整企业需求。此结果要求后续组合方法必须优于这一高效强词法基线，而非旧的逐文档 JSON 查询实现。

### 严格档位对照的全量结果

同一证据和相对排序指令下，58 位全部成功：显式 none 损失 0.20308，未指定档位 0.23240；模型调用均值 2.05 秒对 13.13 秒。研究者级 5,000 次 bootstrap，none 减未指定损失差 -0.02931，95% 区间 [-0.07679,0.01341]；none 减固定画像混合差 -0.03223，区间 [-0.08730,0.02044]。区间包含零，不能宣称显著精度优势。非交替时段和缓存仍可能影响时间，固定随机六位、两轮交替的显式 none/medium 重复对照已完成，结果见下节。

## 补充实验：显式推理档位的交替调用

固定随机种子抽取 6 位 CMU Gold 研究者，每位进行两轮，交替平衡 `none` 与 `medium` 的调用顺序，共 24 次调用。证据构造、排序指令及模型保持一致，档位仅作为请求参数传入。两组无失败；`none` 的 12 次调用报告 reasoning tokens 均为 0，`medium` 为 787–1848。平均模型调用耗时分别为 1.94 秒和 13.74 秒；该时间不含检索及输入构造。

两轮加权成对损失的均值分别为 0.09783 与 0.14452。按研究者宏平均损失计算的 none−medium 差为 −0.02899，研究者级 bootstrap 95% 区间为 [−0.09090, 0.04840]。样本量小且区间跨零，不能据此宣称精度优势或质量等价。此结果支持把推理档位作为效率消融因素，并未证明新的搜索算法优于既有方法。原始结果见 `docs/exploration/interleaved-effort-results.json`，复算脚本为 `experiments/interleaved_effort_report.py`。

## 补充数据审查：原始产业约束与窄化能力任务

修正标题和背景污染后，五条真实企业需求抽取十条连续原文技术条款，每条检索两位教师。保持完整条款及教师固定，将证据从一条扩展至最多三条，每条最多 4,000 字符。两种条件下二十对均获得双模型 unknown 判断；不能据此推断教师没有相关能力，也不能认定真实需求没有可匹配专家。该局部结果仅说明当前候选、截断证据及审核流程不足以证明完整要求。

进一步将真实需求作为背景、以单一教师原始证据生成窄化能力子任务，并要求保留原需求未覆盖项。十个生成样本中，一个未通过引用结构验证，八个未通过完整查询与单项反事实的联合审核，一个成为 silver candidate。其中三例原查询获支持，但反事实也获支持，不能按生成器预设的 unknown 当作负例。审核同时暴露了独立研究方向与联合应用之间的范围歧义，模型审核本身也可能误判，不能把拒绝状态等同于人类判定的语义错误。

原需求、窄化子任务和反事实必须作为不同语义层保存；窄化任务的通过不能计入原产业需求的匹配精度。当前样本规模和验证强度均不足以支撑“高质量产业专家 benchmark”的贡献声明。相关实现为 `demand_multievidence.py` 和 `synthesis_v2.py`，结果保留在本地 artifacts，未公开原始企业或教师材料。

## 范围控制的后续数据试验

针对自由生成中的范围歧义，后续版本将原子研究主题与查询表述分开：代码以统一模板表达“各项分别考察，不要求联合应用”，反事实只替换一个主题。审核口径限定为资料中归属于同一专家的研究主题，不能额外要求独立领导、独著或提供文件；同时核验与原企业需求是否共享具体技术主题。生成器与审核器的最终 schema 保持一致，避免遗漏范围字段。

固定二十条真实需求、每条两个检索候选，共四十个样本中，十四个通过引用结构、完整主题查询、单项反事实及需求主题关联审核，二十个被语义审核拒绝，六个未通过结构验证。十四对包含二十八个查询变体，覆盖十一条需求、十三位教师；仍为 model-audited silver，不是对原需求的完整匹配金标。先前十例对照与此版本同时改变了提示、渲染和审核口径，且调用有随机性，不能将接受率变化解释为单一机制的因果增益。

在上述十四个已获原子主题支持的案例上，另行要求“同一项研究将全部主题联合应用于一套技术方案”。双模型在十二例中均判 unknown，另外两例存在分歧。此项仅说明主题支持与关系支持应分开记录，不能把所有原子节点获支持直接推为联合应用已获支持；没有人工验证，不将其作为指标有效性或精度提升的证明。`scope_metrics.py` 因此分别报告原子覆盖、关系覆盖及必要条件门控，未获得单独证据的关系不由端点支持自动补齐。

## 补充相关工作与公开验证
