# Separate publication version identity from byline agreement

Use the [official arXiv Atom API](https://info.arxiv.org/help/api/user-manual.html)
to sample independently of the CoF case discoveries. Freeze
four calendar-month frames for submissions listed in cs.IR
in January, April, July and October 2024. The search includes
cross-listings. Select 64 papers per month by a fixed salted
hash of their unversioned IDs, without looking at version drift.
There are 262, 270, 273 and 365 papers in the four captured
frames. The released cohort stores IDs, version numbers and
normalized metadata fingerprints.

For each paper, compare the exact version-one entry with the
latest version in the captured feed. Also test 43 papers
whose second version precedes their latest version, using
the second version as a separate target. The two cohorts
overlap. Author-set equality refers to normalized display
names, irrespective of order. This measures the source
byline, not person-entity identity or claimed contributions.

Compare accepting the latest version with three checks
against metadata retained by the index. Check title, title
plus abstract, or title plus author set. A check tries the
latest version first. After a mismatch it tries version one,
then two if it exists and has not already been checked. Count
access attempts after the initial version only. Metadata and
version identities use explicitly numbered official records.
In the historical-version capture all requests returned the
exact requested IDs and every required record was available.

## Results

| Indexed version | Policy | Exact version | Wrong author set | Additional version reads |
| --- | --- | ---: | ---: | ---: |
| v1, 256 works | Latest | 157 | 15 | 0 |
| v1 | Title | 179 | 9 | 22 |
| v1 | Title and abstract | 211 | 5 | 54 |
| v1 | Title and author set | 188 | 0 | 31 |
| Historical v2, 43 works | Latest | 0 | 2 | 0 |
| Historical v2 | Title | 2 | 3 | 13 |
| Historical v2 | Title and abstract | 10 | 3 | 35 |
| Historical v2 | Title and author set | 5 | 0 | 17 |

Latest differs from v1 in the normalized title for 22
papers, abstract for 49 and ordered byline for 18. The
author set differs for 15 papers, including nine whose
title is unchanged. PolyCF is a direct example where
the title and abstract remain the same while the author
set changes. [First version](https://arxiv.org/abs/2401.12590v1) ·
[Second version](https://arxiv.org/abs/2401.12590v2).

The author-set rule has zero accepted set mismatches by
construction, given access to the indexed roster. It still
returns some wrong versions, including one wrong ordered
byline per target cohort. For the historical second-version
target, title and abstract checks even increase the count
of author-set mismatches. These results support recording
an immutable version ID when available at ingestion.
They give no estimates of expert relevance, contribution
attribution, arbitrary version-resolution accuracy or latency
under network load. Additional reads are replayed lookup counts.

## Reproduce

Run the acquisition and analysis using a fresh output directory.
Reuse the saved Atom responses with `--offline` for the same
snapshot. This reproduction generated byte-identical cohort
and aggregate JSON in offline mode.

```sh
PYTHONPATH=src:. python -m experiments.retrieval.arxiv_source_version_benchmark \
  LOCAL_FEED_CACHE NEW_OUTPUT_DIRECTORY
```

The released hashed cohort can also be scored directly with
`summarize(cohort, 1)` and `summarize(cohort, 2)` from the
same module. It contains no paper abstracts.
