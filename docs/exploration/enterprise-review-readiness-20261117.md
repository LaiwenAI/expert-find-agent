# Enterprise review readiness

The local fresh-enterprise review file contains 700 candidate views: 560 development and 140 held-out. All annotation fields are null, including grade, evidence citations, mechanism, assumptions, ownership verification and annotator. The exported review rows have no explicit silver-grade field. This check does not establish that reviewers are blinded to candidate-generation methods or that text itself cannot reveal source identity.

The separate judgment file records 183 model-silver grades, 377 unjudged development views and 140 unjudged held-out views. None of the 700 review rows contains a completed human annotation. The candidate pool was constructed using dense retrieval and random views and is not an exhaustive or unbiased pool. Human judgments must be independently collected, source ownership checked and missing labels retained before reporting expert-ranking accuracy. The held-out cases must remain unavailable for iterative method tuning.

All 200 saved dense-baseline rankings are permutations of their query's seven frozen candidates, and the 700 query/expert snapshots cover exactly those candidates. The frozen baseline protocol says both arms use those snapshots and cached vectors; paper-max considers paper sources while view-max considers all visible snapshot sources. Consequently, candidate identity is controlled but source scope is intentionally different. Results should not be described as a same-evidence-content comparison or as end-to-end latency: the replay excludes full source text outside the snapshot prefix and uses cached vectors.

The legacy agent benchmark saves its complete response, so newly produced successful records include run, retrieval and tree timings. Its outer per-query timer also includes exception handling, while agent initialization occurs before that timer. Existing output files are resumed based on the benchmark manifest fingerprint, not an agent-code fingerprint. Run the modified agent into a fresh output directory; do not mix old and new timing records or interpret the measured run time as including index construction or initialization.
