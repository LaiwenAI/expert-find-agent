# Cost and abstention baseline

Xie et al., "Over-Searching in Search-Augmented Large Language Models," EACL 2026, examine answerable and unanswerable question answering and define Tokens Per Correctness (TPC): total weighted generated tokens, input tokens and search calls divided by the number of correct responses. They use 0.25 for input tokens and 500 for each search call, and define the result as infinity when no response is correct. Their training-free prompt and corpus interventions are task-specific; this repository has not reproduced their reported results. Source: https://aclanthology.org/2026.eacl-long.361/.

The implementation in `src/expert_search/cost_metrics.py` provides this inherited baseline. It requires an independently supplied binary correctness judgment for each attempt. For missing judgments, a separate interval assigns all unknowns correct or incorrect under an independent box assumption. That interval is deterministic, not a confidence interval; it does not repair incorrect labels and may be broad or infinite. Coefficients must be fixed before comparing methods and are not a substitute for wall-clock latency or monetary cost.

In expert search, unobserved evidence is not a negative capability label. A valid abstention benchmark must define a frozen evidence scope and independently establish whether a supported recommendation can be made within it. A system may correctly report insufficient support without claiming the expert cannot solve the problem. Existing enterprise expert-fit labels are incomplete, so neither TPC nor the interval has yet been evaluated as a reliable industrial outcome metric.
# Time-integrated documented support

`time_integrated_gain_interval` in `src/expert_search/evaluation_gain.py` complements point-in-time actionable gain with the area under the latest completed-result gain curve, divided by a prespecified horizon. It credits zero before the first result, retains unknown-grade lower/upper bounds, and replaces the prior snapshot when a later result is worse. Thus early provisional results cannot be counted as permanently available after replacement. This is an application of an area-under-curve summary, not a new theorem; labels must refer to the exact shown evidence view. Bounds address missing grades, not sampling uncertainty or annotation errors. Compare methods at the same horizon, include failures, and report standard quality and latency alongside this summary. No human-labeled enterprise result is available yet.

As a calculation check, `experiments.retrieval.cof_deadline_gain` replays all 73 SIGIR reviewer-matching queries from the existing shared-packing experiment with a post-hoc 30-second horizon. Binary gains use the original soft/hard reviewer labels, not evidence-support labels. Full, similarity and coverage mean time-integrated gains are 0.209/0.099, 0.381/0.183 and 0.340/0.155 for soft/hard respectively. The corresponding measured-component arrival means are 14.12, 2.55 and 2.77 seconds; 67, 73 and 73 results arrive by the horizon. These numbers include observed rate-limit waits in a sequential shared limiter, so order and earlier traffic can strongly affect them; they exclude initialization, query encoding and other overhead. Failed requests retain the original coarse fallback after failure. The horizon was selected after observing prior results. This is an exploratory reviewer-matching demonstration, not a controlled latency comparison, a significance claim, or evidence of enterprise expert fit.
